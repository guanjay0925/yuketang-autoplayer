# yuketang-autoplayer — 雨课堂视频自动连播脚本

基于 **Playwright + Chrome DevTools Protocol (CDP)** 接管专属 Edge 浏览器，自动连播雨课堂（www.yuketang.cn）课程视频的 Python 脚本。带**节点级完成度判定**、防挂机、断线自愈，开起来就能整门课自动刷完。

---

## ✨ 功能特性

| 特性 | 说明 |
|---|---|
| 🔒 专属隔离浏览器 | 使用独立 user-data-dir（如 `D:\Edge_Auto_Profile`），与日常 Edge 完全隔离，不动默认配置、插件、主页 |
| 🤖 自动拉起浏览器 | 9222 调试端口无浏览器时，`subprocess.Popen` 自动启动专属 Edge 并等待 3 秒重连 |
| 🎯 精准节点过滤 | 只点击目录树中类型标签含「视频」的节点（`.leaf-item-tag`），绝不点击图文/讨论/作业/考试 |
| 🔇 强制静音 + 原速 | 锁死 `muted=True` 与 `playbackRate=1.0`（平台 2 倍速不计学习进度）；挂 ratechange/volumechange/canplay/playing/timeupdate 五类监听，播放器偷偷解锁也会被拉回 |
| ✅ 节点级完成度判定 | 只看左侧目录「当前激活节点」自己的状态——圆圈勾图标或「已完成」文字才算完成；**绝不读页面全局「完成度：XX%」**（那是全课程/其他视频的进度，误用会导致同一视频反复重播） |
| 🔁 播完未打勾保险 | 视频播完但平台还没打勾：先等一个轮询周期给平台记录时间 → 仍未打勾才归零重播（最多 3 轮防死循环）→ 仍无标记则带警告跳下一节 |
| ⏭️ 打勾即跳 | 当前节点一旦显示「已完成」，立即点击下一个视频节点；已完成的视频直接秒过 |
| 🛡️ 防挂机 | 播放进度连续 30 秒未动 → 自动 `video.play()` + 真实鼠标点击视频区域恢复 |
| 🩺 目标列表自愈 | 每轮用 HTTP 直查 `:9222/json` 交叉验证目标列表；学习页已打开但旧连接感知不到（例如脚本先启动、用户后开标签页）时自动重建 CDP 连接 |
| 🪟 弹窗自动处理 | 自动点击「确定 / 继续学习 / 知道了」类正向按钮 |

## 🚀 快速开始

### 第 0 步：准备专属浏览器（推荐，一次性）

Edge 136+ 禁止在默认用户配置目录启用 CDP，因此必须用独立配置目录。两种方式任选：

**方式 A（推荐）**：在桌面创建快捷方式「刷课专属Edge」，目标为：

```text
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --user-data-dir="D:\Edge_Auto_Profile" --remote-debugging-port=9222
```

**方式 B（省事）**：什么都不做——脚本检测到 9222 端口没有浏览器时会**自动拉起**专属 Edge（参数与上面相同）。

> 同一个 user-data-dir 同时只能运行一个 Edge 实例。独立目录首次需要重新登录雨课堂，登录态此后长期保留。

### 第 1 步：启动

双击 `启动雨课堂刷课.bat`（或命令行 `python yuketang_autoplay.py`），弹出控制台窗口显示实时日志：

1. 脚本自动连接（或自动拉起）专属 Edge
2. 未登录时会循环提示「请在浏览器中登录雨课堂并进入视频页面」→ 在专属 Edge 窗口登录（只需第一次）
3. 进入课程的视频学习页（URL 含 `lms-graph`）
4. 控制台出现「播放中 xxx/xxx」日志 → 开始自动刷，之后不用管

### 第 2 步：挂机期间

- 窗口可以最小化，但**不要关闭**学习页标签页
- 目录树里的圆圈勾 ✓ 会一个一个亮起来——那就是刷完的进度
- 全部刷完后日志显示「已是目录中最后一个视频，待机中」

### 停止

关闭控制台窗口或按 `Ctrl+C`。不会关闭浏览器，已刷完的进度都在。

## ⚙️ 可调参数（脚本顶部常量）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `CDP_URL` | `http://localhost:9222` | 调试端口地址 |
| `AUTO_PROFILE` | `D:\Edge_Auto_Profile` | 专属浏览器配置目录 |
| `START_URL` | 雨课堂首页 | 自动拉起 Edge 时先打开的页面 |
| `CHECK_INTERVAL` | `20` 秒 | 轮询间隔（同时也是完成度抓取周期） |
| `TARGET_RATE` | `1.0` | 播放倍速（**勿改**，大于 1x 平台不计进度） |
| `END_MARGIN` | `2.0` 秒 | 临近片尾 2 秒即视为播完 |
| `NEXT_TIMEOUT` | `60` 秒 | 点击下一节后等待新视频加载的最长时间 |
| `MAX_REPLAYS` | `3` | 播完未打勾时的最大重播轮数 |
| `STUCK_SECONDS` | `30` 秒 | 进度停滞多久触发防挂机 |
| `VIDEO_TAG` | `视频` | 只点击类型标签含此字样的目录节点 |

## 🔄 工作流程

```text
启动 → 连接/拉起专属 Edge → 等待登录并进入视频页
  ↓ 每 20 秒一轮
读取当前激活节点状态（圆圈勾图标 / 已完成文字 / 节点自带百分比）
  ├─ 节点已完成 → 点击下一个「视频」节点 → 等新视频加载 → 继续
  └─ 未完成 → 强制静音+原速+播放
        ├─ 正常播放 → 20 秒后再查
        ├─ 进度 30 秒未动 → 防挂机强制恢复
        └─ 视频播完但没打勾 → 等一轮平台打勾 → 归零重播(≤3轮) → 跳下一节
```

**完成度判定依据（实测定稿）**：未完成的视频节点在目录树里状态栏是空的，整段看完后平台才会打上圆圈勾图标或「已完成」文字。脚本据此判定，不再依赖任何全局百分比数字。

## 📖 日志速查

| 日志 | 含义 |
|---|---|
| `播放中 120/901s muted=True 当前节点=未标记` | 正常播放中 |
| `当前节点显示已完成, 切换下一节... [累计N]` | 打勾了，正在跳下一个（N = 已刷完数） |
| `等待平台记录(下轮复查)...` | 视频播完了，等平台打勾（正常，最多等一轮） |
| `第 x/3 轮归零重播` | 平台没打勾，自动重播 |
| `【警告】始终未出现完成标记...跳下一节` | 3 轮都没打勾，建议人工看下这节 |
| `已在目录中最后一个视频, 待机中` | 🎉 全部视频刷完了，去做作业和测验吧 |

## ⚠️ 注意事项

1. **电脑不能睡眠/合盖**——挂机期间请插电并把电源计划设为「从不睡眠」
2. **勿同时运行两个脚本实例**（双击 bat 前确认没有旧控制台还在跑）
3. **只在专属 Edge 里刷**，不要与日常浏览器混用
4. **别手动改倍速**——脚本检测到会强制锁回 1.0x
5. **作业、测验不会自动完成**，脚本只刷视频节点
6. **视频弹题**：脚本只点「继续/确定」类按钮，需要作答的题目请人工处理（卡住时防挂机会强制恢复播放）
7. Edge 被误关没关系，脚本会自动重新拉起；中途电脑重启后重新运行即可

## 🧰 常见问题

**Q：控制台一直提示「请在浏览器中登录雨课堂并进入视频页面」？**
A：在专属 Edge 窗口里登录雨课堂，然后点进课程的视频学习页即可，脚本每 20 秒自动检测。

**Q：某个视频反复重播后跳过了，还显示警告？**
A：说明 3 轮重播后平台仍未给该节点打勾（可能是网络/平台记录延迟）。手动看一眼该视频的完成状态，必要时隔天再跑一遍。

**Q：想换一台电脑/改端口？**
A：改脚本顶部 `CDP_URL` 与 `AUTO_PROFILE` 即可；`启动雨课堂刷课.bat` 里的 Python 路径按实际安装位置修改。

**Q：为什么必须用独立的 user-data-dir？**
A：Edge 136 起禁止在默认用户配置目录开启 CDP 调试端口；独立目录既满足调试要求，又与日常配置完全隔离。
